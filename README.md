# Airbnb Image Extractor — Releases

Public download and auto-update channel for **Airbnb Image Extractor**.

The application source is private. This repository contains only the release
artifacts produced by the project's GitHub Actions pipeline.

> Latest release: [github.com/allen-bmv/airbnb-extractor-desktop-releases/releases/latest](https://github.com/allen-bmv/airbnb-extractor-desktop-releases/releases/latest)

## Download

| Platform | Package | Notes |
| --- | --- | --- |
| Windows 10/11 x64 | [`airbnb-extractor-desktop.exe`](https://github.com/allen-bmv/airbnb-extractor-desktop-releases/releases/latest/download/airbnb-extractor-desktop.exe) | Portable executable. No installer, no admin rights. |
| Linux x64 (Debian/Ubuntu) | `airbnb-extractor-desktop_<version>-1_amd64.deb` | Install with `apt`. See the latest release page. |

Each release also contains release notes and checksums for every asset.

## License

The app requires a license key. One license activates one device.

1. Obtain a key from the administrator.
2. Open **Settings → License**.
3. Paste the key and click **Verify**.

The API returns a device-bound token, stored only on your computer in SQLite.
The key itself is not stored. Moving to another computer requires the
administrator to reset the device. Without a license, extraction requests are
rejected by the API.

## Verify the download

Use the SHA-256 values from `latest.json`.

Windows (PowerShell):

```powershell
$manifest = Invoke-RestMethod `
  "https://github.com/allen-bmv/airbnb-extractor-desktop-releases/releases/latest/download/latest.json"

$asset = $manifest.platforms.'windows-x86_64'
$file = Join-Path $env:TEMP "airbnb-extractor-desktop.exe"

Invoke-WebRequest $asset.url -OutFile $file
(Get-FileHash $file -Algorithm SHA256).Hash.ToLower() -eq $asset.sha256.ToLower()
```

Linux:

```bash
curl -sL \
  https://github.com/allen-bmv/airbnb-extractor-desktop-releases/releases/latest/download/latest.json \
  -o latest.json

python3 - <<'PY'
import json
m = json.load(open("latest.json"))
a = m["platforms"]["linux-x86_64"]
print(a["url"])
print(a["sha256"])
PY

sha256sum airbnb-extractor-desktop_*.deb
```

## Install — Windows

1. Download `airbnb-extractor-desktop.exe`.
2. Put it in a folder you control, for example:
   `%LOCALAPPDATA%\Airbnb Image Extractor\`.
3. Run the executable. No installer or administrator prompt is required.

The executable is a normal GUI application: no console window and no UAC
prompt. It keeps settings and history under:

```text
%APPDATA%\airbnb-image-extractor\
```

### SmartScreen

This project does not currently use a public code-signing certificate. A
freshly downloaded, unsigned executable may show:

```text
Windows protected your PC
More info → Run anyway
```

This is Microsoft Defender SmartScreen, not an application error. You can
verify the SHA-256 against `latest.json` before running it. If the file is only
for your own use, you can also right-click → **Properties** → **Unblock**.

A future release may add Authenticode signing; see
`docs/CODE_SIGNING_WINDOWS.md` in the private source repository.

## Install — Linux (Debian/Ubuntu)

Download the `.deb` from the latest release, then:

```bash
sudo apt install ./airbnb-extractor-desktop_<version>-1_amd64.deb
```

Launch it from the application menu or:

```bash
airbnb-extractor-desktop
```

Install locations:

```text
/usr/bin/airbnb-extractor-desktop
/usr/share/applications/airbnb-extractor-desktop.desktop
/usr/share/icons/hicolor/<size>/apps/airbnb-extractor-desktop.png
```

Settings/history are stored in:

```text
~/.local/share/airbnb-image-extractor/client.db
```

Removing the application:

```bash
sudo apt remove airbnb-extractor-desktop
```

## Automatic updates

Open the app and click **Check update** in the header.

- If a newer version exists, the button becomes **Update to vX**.
- The app downloads the platform asset, verifies its SHA-256, installs it, and
  restarts.
- Windows: the portable `.exe` is replaced by a small PowerShell helper.
- Linux: the `.deb` is installed through `pkexec apt-get install`, so an
  administrator password prompt is expected.
- Development builds do not replace themselves.

The app reads the manifest from:

```text
https://github.com/allen-bmv/airbnb-extractor-desktop-releases/releases/latest/download/latest.json
```

Do not edit release assets manually; the workflow regenerates them.

## Release process

Releases are built from the private source repository:

1. Update `version` in `Cargo.toml`.
2. Commit and push to `main`.
3. Create and push a tag:
   ```bash
   git tag v0.1.2
   git push origin v0.1.2
   ```
4. GitHub Actions builds:
   - Windows portable `.exe` (icon embedded)
   - Linux `.deb` (icons + desktop entry)
   - SHA-256 values and `latest.json`
5. The workflow publishes the assets to this repository.

`v*` tags use the tag name as the release version; it must match `Cargo.toml`.

## Troubleshooting

| Problem | Solution |
| --- | --- |
| SmartScreen “Run anyway” | Verify SHA-256; choose More info → Run anyway, or unblock the file. |
| Linux update asks for password | Expected: `.deb` installation uses `pkexec` / apt. |
| `Check update` reports an error | Confirm the latest release contains `latest.json`. |
| App won’t start on Linux | Run from a terminal to see the error; check Vulkan/OpenGL drivers. |
| Wrong version shown | Download the asset from the latest release and verify the manifest. |
